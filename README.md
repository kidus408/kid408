# 📊 Machine Learning & Data Analysis Projects

This repository contains a collection of **Kaggle-based data analysis and machine learning projects** implemented in **Python**.  
Each notebook focuses on a specific dataset and demonstrates the full workflow:
- Data loading
- Exploratory Data Analysis (EDA)
- Feature processing
- Model building
- Evaluation

---

## 📁 Projects Overview

### 1️⃣ Basic Exploratory Data Analysis for Zomato
**Notebook:** `basic-exploratory-data-analysis-for-zomato.ipynb`  
**Description:**  
Exploratory analysis of the Zomato restaurant dataset to uncover trends, ratings distribution, and location-based insights using Pandas and Matplotlib.

**Tech stack:**  
- Python  
- Pandas  
- NumPy  
- Matplotlib / Seaborn  

---

### 2️⃣ Logistic Regression – Mushroom Classification
**Notebook:** `logistic-regression-of-mushroom-classification.ipynb`  
**Description:**  
A binary classification task using Logistic Regression to predict whether a mushroom is edible or poisonous based on its features.

**Tech stack:**  
- Python  
- Scikit-learn  
- Pandas  

---

### 3️⃣ Salary Prediction with Linear Regression
**Notebook:** `salary-prediction-with-linear-regression.ipynb`  
**Description:**  
A simple regression model to predict salaries based on years of experience using Linear Regression.

**Tech stack:**  
- Python  
- Scikit-learn  
- Pandas  
- Matplotlib
